# Balansis — Official Website

Cinematic, responsive Next.js website for Balansis (`https://balansis.pw`). The site introduces the company, capabilities and Eagle Sentinel flagship concept.

## Run locally

- Node.js 18.17+ (Node 20 LTS recommended)
- `npm install`
- `npm run dev`
- Open http://localhost:3000

## Production

- `npm run build`
- `npm start`

## Deploy

Import this repository into Vercel, deploy with the Next.js preset, then add `balansis.pw` in project Domains and configure the DNS records Vercel provides.

## Important project-status note

Eagle Sentinel is presented as a concept/prototype-development project. Its proposed capabilities are not represented as independently validated or operational.

## Before launch

Confirm the public company description and contact mailbox (`hello@balansis.pw`), and add a privacy policy if visitor data is collected.
